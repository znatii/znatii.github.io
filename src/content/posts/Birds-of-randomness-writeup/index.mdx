Como se puede ver que la semilla se divide por 30268, el resultado se divide por 30306 y el siguiente 30322 y nos quedamos con el resto de cada operacion  (x,y,z)
La funcion _goToNextStation_ es la que calcula la clave privada y el siguiente punto (clave pública), para que se pueda considerar una clave valida, se rotará la seed (x,y,z) hasta que los tres sean primos. Se ve que se usa un PRNG de 5 digitos (algoritmo WichmannHill). Por lo que estos números pueden llegar a ser predecibles y ademas $d$ puede llegar a ser factorizable (producto de 3 primos de 5 digitos)

### Ataque 
Como se ha visto, $d$ no es excesivamente grande (factor de 3 primos de 5 digitos), $d = x*y*z$ donde $x,y,z <30323$, entonces en el peor de los casos $d=30323³=2.7*10^{13}$ lo que nos queda $√d ≈ 5.2 × 10⁶$, computacionalmente manejable.
Ademas conocemos la cota superior $d<30269 × 30307 × 30323$, un dato importante para resolver el problema del algoritmo discreto.
El camino a seguir parece que es el siguiente:
1. Calcular $d1$ resolviendo el ECDLP, Problema del logaritmo discreto usando el ataque de Baby-Step Gigant-Step 
2. Factorizar $d1$ en sus tres factores primos
3. Predecir el siguiente estado del PRNG
4. Tenemos 6 oportunidades ya que aunque conozcamos los 3 factores no sabemos el orden en el que se usaron, por lo que tenemos 6 posibilidades

### Writeup

Vamos a seguir los pasos que comentamos antes, en primer lugar vamos a definir la curva.
```python
import math  
from itertools import permutations  
from ecdsa import ellipticcurve as ecc  
from Crypto.Util.number import isPrime  
  
# Curva elíptica  
p = 17101937747109687265202713197737423  
Gx = 3543321030468950376213178213609418  
Gy = 14807290861072031659976937040569354  
ec_order = 17101937747109687496599931614463506  
E = ecc.CurveFp(p, 2, 3)  
G = ecc.Point(E, Gx, Gy, ec_order)
```
Para encontrar los factores de $d$ necesitaremos la lista de primos menores de **30323** ya que es el modulo mayor, por lo que ninguno de los factores sera mayor.
```python
def primos(n):  
    is_prime = [True] * (n + 1)  
    is_prime[0] = is_prime[1] = False  
    for i in range(2, int(math.sqrt(n)) + 1):  
        if is_prime[i]:  
            for j in range(i * i, n + 1, i):  
                is_prime[j] = False  
    return [i for i in range(2, n + 1) if is_prime[i]]
    
primes_list = primos(30323)
```
También necesitaremos el codigo del PRNG para simular el estado y predecir las coordenadas, por lo que replicamos exactamente la lógica del reto.
```python
def rotate(seed):
    x, y, z = seed
    x = (171 * x) % 30269
    y = (172 * y) % 30307
    z = (170 * z) % 30323
    return (x, y, z)

def next_station(state):
    while True:
        state = rotate(state)
        x, y, z = state
        if isPrime(x) and isPrime(y) and isPrime(z):
            d = x * y * z
            P = d * G
            return (int(P.x()), int(P.y()))
```
Ahora, necesitamos el código del ataque que vamos a usar en este caso, Baby-Step Gigant-Step
1. **Baby Steps**: Precalcula y almacena $j×G$ para $j = 1...m$
2. **Giant Steps**: Calcula $P - i×(m×G)$ para $i = 1...m$
3. **Busca coincidencia**: Cuando encuentra que $j×G = P - i×(m×G)$, entonces $d = j + i×m$

```python
# Algoritmo baby-step giant-step para resolver el logaritmo discreto  
def BSGS(P, G, M):  #Punto, Curva, mayor d posible
    m = int(math.isqrt(M)) + 1  
    print(f"[+] Using m = {m}")  
  
    # Precalcular m*G  
    mG = m * G  
    print("[+] Computed mG")  
  
    # Baby steps: almacenar puntos j*G para j=1..m  
    baby = {}  
    current = G  
    for j in range(1, m + 1):  
        if j % 100000 == 0:  
            print(f"[+] Baby step {j}/{m}")  
        x = int(current.x())  
        y = int(current.y())  
        baby[(x, y)] = j  
        current = current + G  
    print("[+] Baby steps completed")  
  
    # Giant steps: buscar P - i*m*G en baby steps  
    current = P  
    minus_mG = -mG  
    for i in range(0, m + 1):  
        if i % 100000 == 0:  
            print(f"[+] Giant step {i}/{m}")  
        if current is None:  
            d = i * m  
            if 1 <= d <= M:  
                return d  
        else:  
            x = int(current.x())  
            y = int(current.y())  
            if (x, y) in baby:  
                j = baby[(x, y)]  
                d = i * m + j  
                if 1 <= d <= M:  
                    return d  
        current = current + minus_mG  
    return None
```

Finalmente, con los tres primos podremos predecir el siguiente punto, el cual sera la solución, teniendo en cuenta que tenemos 6 posibles combinaciones (permutacion de 3)  y probamos cual de las 6 combinaciones resuelve el reto.
```python
# Generar permutaciones de los factores
candidates = list(permutations(factors))
next_points = []
for cand in candidates:
    next_point = next_station(cand)
    next_points.append(next_point)
```
